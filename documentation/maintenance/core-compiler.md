# 核心编译器维护指南

## 1. 模块概述

核心编译器是 Rusty-TypeScript 项目的核心组件，负责 TypeScript 源代码的词法分析、语法分析、AST 构建和代码生成。

## 2. 文件位置

- **主文件**：`compilers/typescript/src/lib.rs`
- **词法分析器**：`compilers/typescript/src/lexer.rs`
- **语法分析器**：`compilers/typescript/src/parser.rs`
- **AST 定义**：`compilers/typescript/src/ast.rs`
- **代码生成**：`compilers/typescript/src/codegen.rs`
- **错误处理**：`compilers/typescript/src/errors.rs`

## 3. 主要功能

### 3.1 词法分析

- 将 TypeScript 源代码转换为词法单元 (tokens)
- 处理关键字、标识符、字面量、运算符等
- 生成词法错误信息

### 3.2 语法分析

- 将词法单元转换为抽象语法树 (AST)
- 实现 TypeScript 语法规则
- 生成语法错误信息

### 3.3 AST 构建

- 定义 AST 节点结构
- 处理 TypeScript 特有的语法结构
- 支持类型注解和类型声明

### 3.4 代码生成

- 将 AST 转换为中间表示 (IR)
- 生成优化的代码
- 处理类型信息

### 3.5 错误处理

- 生成详细的错误信息
- 提供错误恢复机制
- 支持错误定位和修复建议

## 5. 常见问题与解决方案

### 5.1 词法分析问题

**问题**：词法分析器无法识别某些特殊字符
**解决方案**：
- 检查词法规则定义
- 确保所有特殊字符都有正确的处理逻辑
- 添加测试用例验证

### 5.2 语法分析问题

**问题**：语法分析器在处理复杂表达式时出错
**解决方案**：
- 检查语法规则的优先级和关联性
- 确保递归下降解析器的正确性
- 添加详细的错误信息

### 5.3 AST 构建问题

**问题**：AST 节点结构不完整或不正确
**解决方案**：
- 检查 AST 节点定义
- 确保所有语法结构都有对应的 AST 节点
- 添加 AST 验证机制

### 5.4 代码生成问题

**问题**：生成的中间表示不正确
**解决方案**：
- 检查代码生成逻辑
- 确保类型信息正确传递
- 添加代码生成测试

### 5.5 性能问题

**问题**：编译速度慢
**解决方案**：
- 优化词法和语法分析算法
- 实现缓存机制
- 减少内存分配
